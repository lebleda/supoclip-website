Built for creators who ship shorts.

Every stage of the clipping pipeline — transcription, selection, rendering, editing — in one open-source app you control.

AI clip selection

An LLM reads the full transcript and returns the 3–7 most clip-worthy segments, each with start/end timestamps and a virality score. Supports Gemini, GPT, Claude, and local Ollama models — switch with one env var.

Virality scoring

Every clip is scored on hook, engagement, value, and shareability. Sort your queue by score and post the winners first.

Smart vertical crop

Face detection keeps the speaker centered in the 9:16 frame across the whole clip, so subjects never drift off-screen.

Word-synced subtitles

AssemblyAI word-level timestamps drive captions that highlight the current word. Pick from caption templates with animation styles and custom fonts.

Hook titles

An AI-written headline is burned into the top of each clip's opening seconds to stop the scroll before the first word.

B-roll & transitions

Optional Pexels stock footage overlays and transition effects between segments to keep retention high.

Built-in editor

Trim, split, and merge clips in the browser, then export with platform presets for TikTok, Instagram Reels, and YouTube Shorts.

Real-time progress

Live pipeline updates stream to the browser while your video processes — transcription, selection, rendering — with per-stage status.

REST API & MCP server

API keys authenticate the backend directly for automation, and an MCP server lets you drive SupoClip from Claude, Cursor, and other MCP clients.

Multi-platform export

Platform presets for TikTok, Reels, and Shorts, plus an iOS app that runs the same hosted pipeline from your phone.
