# SupoClip Website

Modern, responsive marketing site for [SupoClip](https://github.com/FujiwaraChoki/supoclip) — an open-source, AI-powered video clipping tool. Free forever, no subscription, no watermarks.

## Pages

- `index.html` — Home (hero, features, how it works, pricing, testimonials, FAQ, CTA)
- `features.html` — Feature details
- `pricing.html` — Free forever positioning
- `docs.html` — Self-host quick start
- `about.html` — Why SupoClip exists
- `privacy.html` / `terms.html`

## Tech

Static HTML + Tailwind CSS (CDN) + vanilla JS. No build step. Deploy anywhere (GitHub Pages, Vercel, Netlify, Cloudflare Pages).

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
