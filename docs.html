Self-host in 5 minutes.

Docker Compose brings up the frontend, backend, worker, Postgres, and Redis. You need an AssemblyAI key and one LLM provider key.

1. Clone

git clone https://github.com/FujiwaraChoki/supoclip.git cd supoclip

2. Configure

Create a .env in the repo root:

ASSEMBLY_AI_API_KEY=your_assemblyai_api_key LLM=google-gla:gemini-3-flash-preview GOOGLE_API_KEY=your_google_api_key

Use any supported LLM: OpenAI, Anthropic, Google, or a local Ollama model (LLM=ollama:...).

3. Run

docker-compose up -d

First startup takes a few minutes. Watch logs with docker-compose logs -f. Then open http://localhost:3107, create an account, and start clipping. Backend API at http://localhost:8000, docs at /docs.

Without Docker

Backend: cd backend && uv sync && uvicorn src.main:app --reload --host 0.0.0.0 --port 8000. Worker: .venv/bin/arq src.workers.tasks.WorkerSettings. Frontend: cd frontend && pnpm install && pnpm run dev.

API & MCP

API keys from /settings/api-keys authenticate the backend directly. The mcp/ server lets you drive SupoClip from Claude, Cursor, and other MCP clients.

Need more?

Configuration, custom ports, public URLs, Ollama setup, B-roll, analytics, and troubleshooting all live in the repo's docs/ folder.
